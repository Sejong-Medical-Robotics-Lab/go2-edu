# Go2 주행 실습 — Waypoint 및 LiDAR 장애물 정지

이번 실습에서는 Python으로 직접 ROS2 노드를 작성하여 다음 두 가지 동작을 구현합니다.

```text
실습 1
정해진 순서에 따라 이동하는 Waypoint 주행

실습 2
LiDAR로 전방 장애물을 감지하여 자동 정지 및 재출발
```

두 실습은 각각 코드를 작성한 뒤 **바로 빌드하고 실행하여 결과를 확인**합니다.

> `/cmd_vel`을 발행하는 여러 노드를 동시에 실행하지 않도록 주의합니다.

# 1. Waypoint 순차 주행

정해진 속도와 시간에 따라 Go2가 전진과 회전을 순서대로 수행하도록 만들어 봅니다.

이번 예제의 동작 순서는 다음과 같습니다.

```text
전진
→ 정지
→ 좌회전
→ 정지
→ 전진
→ 정지
→ 우회전
→ 정지
→ 전진
→ 최종 정지
```

실제 위치 좌표를 기반으로 이동하는 자율주행 Waypoint가 아니라,

```text
정해진 속도
+
정해진 시간
```

을 순서대로 실행하는 간단한 Waypoint 주행 실습입니다.

작성 표 예시

| 구간 | 동작 (함수/명령)         | 값                                    |                 시간(초) | 기대 결과  |
| -- | ------------------ | ------------------------------------ | --------------------: | ------ |
| 출발 | 보행 가능 상태 확인        | 리모컨 Start                            |                     - | 주행 준비  |
| 1  | 전진 → 정지            | `linear.x = 0.3`                     |             1.0 + 1.0 | WP1 도달 |
| 2  | 좌회전 → 정지 → 전진 → 정지 | `angular.z = +0.5`, `linear.x = 0.3` | 1.5 + 1.0 + 1.0 + 1.0 | WP2 도달 |
| 3  | 우회전 → 정지 → 전진 → 정지 | `angular.z = -0.5`, `linear.x = 0.3` | 1.5 + 1.0 + 1.0 + 1.0 | WP3 도달 |
| 종료 | 정지                 | `linear.x = 0.0`, `angular.z = 0.0`  |                   1.0 | 최종 정지  |

```python
import rclpy
from rclpy.node import Node

from geometry_msgs.msg import Twist


class StudentWaypoint(Node):

    def __init__(self):
        super().__init__('student_waypoint')

        # /cmd_vel 토픽으로 속도 명령 발행
        self.publisher_ = self.create_publisher(
            Twist,
            '/cmd_vel',
            10
        )

        # 전진 속도와 시간
        self.forward_speed = 0.3
        self.forward_time = 1.0

        # 회전 속도와 시간
        self.turn_speed = 0.5
        self.turn_time = 1.5

        # 각 동작 사이의 정지 시간
        self.pause_time = 1.0

        # --------------------------------------------------
        # 동작 순서
        #
        # 각 항목:
        # (동작 이름, 실행 시간, linear.x, angular.z)
        # --------------------------------------------------

        self.steps = [
            (
                '첫 번째 구간 전진',
                self.forward_time,
                self.forward_speed,
                0.0
            ),

            (
                '정지',
                self.pause_time,
                0.0,
                0.0
            ),

            (
                '왼쪽 회전',
                self.turn_time,
                0.0,
                self.turn_speed
            ),

            (
                '정지',
                self.pause_time,
                0.0,
                0.0
            ),

            (
                '두 번째 구간 전진',
                self.forward_time,
                self.forward_speed,
                0.0
            ),

            (
                '정지',
                self.pause_time,
                0.0,
                0.0
            ),

            (
                '오른쪽 회전',
                self.turn_time,
                0.0,
                -self.turn_speed
            ),

            (
                '정지',
                self.pause_time,
                0.0,
                0.0
            ),

            (
                '마지막 구간 전진',
                self.forward_time,
                self.forward_speed,
                0.0
            ),

            (
                '최종 정지',
                self.pause_time,
                0.0,
                0.0
            ),
        ]

        # 현재 실행 중인 단계 번호
        self.step_index = 0

        # 현재 단계가 시작된 시간
        self.step_start_time = self.get_clock().now()

        # 0.1초마다 timer_callback 실행
        self.timer = self.create_timer(
            0.1,
            self.timer_callback
        )

        self.get_logger().info(
            'Waypoint 주행을 시작합니다.'
        )

    def timer_callback(self):

        # 모든 동작을 수행한 경우
        if self.step_index >= len(self.steps):

            self.publish_stop()

            self.timer.cancel()

            self.get_logger().info(
                'Waypoint 주행이 끝났습니다.'
            )

            return

        # 현재 단계 정보 가져오기
        name, duration, linear_x, angular_z = \
            self.steps[self.step_index]

        # 현재 단계가 시작된 후 지난 시간 계산
        elapsed_time = (
            self.get_clock().now()
            - self.step_start_time
        ).nanoseconds / 1e9

        # 현재 단계의 실행 시간이 끝난 경우
        if elapsed_time >= duration:

            # 다음 단계로 이동
            self.step_index += 1

            # 새로운 단계 시작 시간 저장
            self.step_start_time = self.get_clock().now()

            if self.step_index < len(self.steps):

                next_name = self.steps[
                    self.step_index
                ][0]

                self.get_logger().info(
                    next_name
                )

            return

        # 현재 단계의 속도 명령 생성
        msg = Twist()

        msg.linear.x = linear_x
        msg.angular.z = angular_z

        # /cmd_vel 발행
        self.publisher_.publish(msg)

    def publish_stop(self):

        # 정지 명령 생성
        msg = Twist()

        msg.linear.x = 0.0
        msg.angular.z = 0.0

        # /cmd_vel로 정지 명령 발행
        self.publisher_.publish(msg)


def main(args=None):

    rclpy.init(args=args)

    node = StudentWaypoint()

    try:
        rclpy.spin(node)

    except KeyboardInterrupt:

        # Ctrl + C로 종료할 때 정지 명령 전송
        node.publish_stop()

    finally:

        node.destroy_node()

        if rclpy.ok():
            rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## 1.2 코드 구조 확인

Waypoint 노드는 다음 순서로 동작합니다.

```text
steps에 이동 순서 저장
        ↓
0.1초마다 timer_callback 실행
        ↓
현재 단계의 Twist 생성
        ↓
/cmd_vel 발행
        ↓
정해진 시간이 지나면 다음 단계 실행
        ↓
모든 단계 종료
        ↓
정지 명령 발행
```

예를 들어:

```python
(
    '첫 번째 구간 전진',
    self.forward_time,
    self.forward_speed,
    0.0
)
```

은 다음 의미입니다.

```text
동작 이름
→ 첫 번째 구간 전진

실행 시간
→ forward_time

linear.x
→ forward_speed

angular.z
→ 0.0
```

따라서 Go2가 일정 시간 동안 직진합니다.

왼쪽 회전은:

```python
(
    '왼쪽 회전',
    self.turn_time,
    0.0,
    self.turn_speed
)
```

오른쪽 회전은:

```python
(
    '오른쪽 회전',
    self.turn_time,
    0.0,
    -self.turn_speed
)
```

처럼 `angular.z`의 부호를 다르게 사용합니다.

# 5. LiDAR 장애물 감지 및 정지

이번에는 Hesai LiDAR의 `/lidar_points`를 구독하여 전방 장애물을 감지합니다.

동작 구조는 다음과 같습니다.

```text
/lidar_points 수신
        ↓
로봇 앞쪽 PointCloud만 선택
        ↓
각 점까지의 거리 계산
        ↓
가장 가까운 거리 확인
        ↓
0.6 m 미만
→ 정지

0.8 m 초과
→ 다시 출발
        ↓
/cmd_vel 발행
```

정지 거리와 다시 출발하는 거리를 다르게 설정한 이유는 장애물이 경계 부근에 있을 때:

```text
정지
→ 출발
→ 정지
→ 출발
```

이 빠르게 반복되는 현상을 줄이기 위해서입니다.

이러한 방식을 **히스테리시스(Hysteresis)**라고 합니다.

아래 코드를 붙여 넣고 저장합니다.

```python
import math

import numpy as np

import rclpy
from rclpy.node import Node
from rclpy.qos import qos_profile_sensor_data

from geometry_msgs.msg import Twist
from sensor_msgs.msg import PointCloud2


class StudentLidarStop(Node):

    def __init__(self):
        super().__init__('student_lidar_stop')

        # --------------------------------------------------
        # /cmd_vel Publisher
        # --------------------------------------------------

        self.publisher_ = self.create_publisher(
            Twist,
            '/cmd_vel',
            10
        )

        # --------------------------------------------------
        # Hesai LiDAR Subscriber
        # --------------------------------------------------

        self.subscription = self.create_subscription(
            PointCloud2,
            '/lidar_points',
            self.lidar_callback,
            qos_profile_sensor_data
        )

        # False = 주행 중
        # True = 장애물 감지로 정지 중
        self.stopped = False

        # 장애물을 감지하면 정지할 거리
        self.stop_distance = 0.6

        # 다시 출발할 거리
        self.restart_distance = 0.8

        # 가장 최근에 측정한 최소 거리
        self.min_distance = None

        # --------------------------------------------------
        # 0.1초마다 /cmd_vel 발행
        # --------------------------------------------------

        self.cmd_timer = self.create_timer(
            0.1,
            self.publish_cmd
        )

        self.get_logger().info(
            'Student LiDAR stop node started'
        )

    def lidar_callback(self, msg):

        # --------------------------------------------------
        # Hesai PointCloud2 데이터 구조 정의
        # --------------------------------------------------

        point_dtype = np.dtype({
            'names': [
                'x',
                'y',
                'z',
                'intensity',
                'ring',
                'timestamp'
            ],

            'formats': [
                '<f4',
                '<f4',
                '<f4',
                '<f4',
                '<u2',
                '<f8'
            ],

            'offsets': [
                0,
                4,
                8,
                12,
                16,
                18
            ],

            'itemsize': msg.point_step
        })

        # PointCloud2의 byte 데이터를
        # numpy 배열로 변환
        points = np.frombuffer(
            msg.data,
            dtype=point_dtype,
            count=msg.width * msg.height
        )

        # PointCloud가 비어 있으면 종료
        if points.size == 0:
            return

        # x, y, z 좌표 추출
        x = points['x']
        y = points['y']
        z = points['z']

        # --------------------------------------------------
        # Go2 전방 영역에 있는 점만 선택
        # --------------------------------------------------

        mask = (
            np.isfinite(x) &
            np.isfinite(y) &
            np.isfinite(z) &

            # 로봇 바로 주변의 점 제외
            (x > 0.2) &

            # 최대 3 m까지 확인
            (x < 3.0) &

            # 좌우 폭 ±0.4 m
            (np.abs(y) < 0.4) &

            # 너무 높거나 낮은 점 제외
            (z > -0.5) &
            (z < 0.5)
        )

        # --------------------------------------------------
        # 전방에 유효한 점이 없는 경우
        # --------------------------------------------------

        if not np.any(mask):

            self.min_distance = None

            # 이전에 장애물 때문에 정지했던 경우
            # 다시 출발 상태로 변경
            if self.stopped:

                self.stopped = False

                self.get_logger().info(
                    'GO resumed | no obstacle'
                )

            return

        # 전방 점들만 추출
        front_x = x[mask]
        front_y = y[mask]

        # --------------------------------------------------
        # 각 점까지의 평면 거리 계산
        #
        # distance² = x² + y²
        # --------------------------------------------------

        distance_sq = (
            front_x * front_x
            + front_y * front_y
        )

        # 가장 가까운 점 찾기
        min_index = np.argmin(
            distance_sq
        )

        # 최소 거리 계산
        self.min_distance = math.sqrt(
            float(
                distance_sq[min_index]
            )
        )

        # --------------------------------------------------
        # 히스테리시스
        # --------------------------------------------------

        # 주행 중이며
        # 장애물이 0.6 m보다 가까우면 정지
        if (
            not self.stopped
            and self.min_distance < self.stop_distance
        ):

            self.stopped = True

            self.get_logger().info(
                f'STOP triggered | '
                f'{self.min_distance:.2f} m'
            )

        # 정지 중이며
        # 장애물이 0.8 m보다 멀어지면 재출발
        elif (
            self.stopped
            and self.min_distance > self.restart_distance
        ):

            self.stopped = False

            self.get_logger().info(
                f'GO resumed | '
                f'{self.min_distance:.2f} m'
            )

    def publish_cmd(self):

        # --------------------------------------------------
        # 0.1초마다 /cmd_vel 발행
        # --------------------------------------------------

        cmd = Twist()

        if self.stopped:

            # 장애물 감지
            # → 정지
            cmd.linear.x = 0.0

        else:

            # 장애물이 없으면
            # → 0.2 m/s로 전진
            cmd.linear.x = 0.2

        cmd.linear.y = 0.0
        cmd.angular.z = 0.0

        self.publisher_.publish(cmd)

    def publish_stop(self):

        # --------------------------------------------------
        # 프로그램 종료 시 정지 명령 발행
        # --------------------------------------------------

        stop = Twist()

        stop.linear.x = 0.0
        stop.linear.y = 0.0
        stop.angular.z = 0.0

        self.publisher_.publish(stop)


def main(args=None):

    rclpy.init(args=args)

    node = StudentLidarStop()

    try:

        rclpy.spin(node)

    except KeyboardInterrupt:

        pass

    finally:

        # 종료 전에 정지 명령 전송
        node.publish_stop()

        node.destroy_node()

        if rclpy.ok():
            rclpy.shutdown()


if __name__ == '__main__':
    main()
```

# 10. LiDAR Stop 동작 확인

기본 설정은 다음과 같습니다.

```text
전진 속도
→ 0.2 m/s

장애물 거리 < 0.6 m
→ 정지

장애물 거리 > 0.8 m
→ 다시 전진
```

실습에서는 로봇이 천천히 전진하는 상태에서 전방에 장애물을 위치시켜 동작을 확인합니다.

예상 흐름:

```text
장애물 없음
→ Go2 전진

장애물이 가까워짐
→ 최소 거리 감소

0.6 m 미만
→ stopped = True
→ /cmd_vel linear.x = 0.0
→ Go2 정지

장애물 제거

0.8 m 초과
→ stopped = False
→ /cmd_vel linear.x = 0.2
→ Go2 재출발
```

터미널에는 다음과 같은 로그가 나타납니다.

```text
STOP triggered | 0.55 m
```

장애물을 치우면:

```text
GO resumed | 0.91 m
```

와 같이 표시될 수 있습니다.

# 11. LiDAR 코드에서 확인할 핵심

## 전방 영역 선택

```python
mask = (
    np.isfinite(x) &
    np.isfinite(y) &
    np.isfinite(z) &
    (x > 0.2) &
    (x < 3.0) &
    (np.abs(y) < 0.4) &
    (z > -0.5) &
    (z < 0.5)
)
```

LiDAR의 모든 점을 장애물로 판단하는 것이 아니라 **Go2 앞쪽에 있는 점만 선택**합니다.

현재 조건은 대략 다음 공간입니다.

```text
전방 거리
0.2 m ~ 3.0 m

좌우 범위
-0.4 m ~ +0.4 m

높이 범위
-0.5 m ~ +0.5 m
```

---

## 거리 계산

전방에 선택된 각 점의 `x`, `y` 값을 이용합니다.

```python
distance_sq = (
    front_x * front_x
    + front_y * front_y
)
```

즉:

```text
x² + y²
```

를 먼저 계산하고 가장 작은 값을 찾습니다.

```python
min_index = np.argmin(
    distance_sq
)
```

그다음 제곱근을 이용해 실제 거리를 계산합니다.

```python
self.min_distance = math.sqrt(
    float(
        distance_sq[min_index]
    )
)
```

따라서 코드에서는 **Go2 전방 영역에 존재하는 LiDAR 점 중 가장 가까운 점까지의 거리**를 사용합니다.

---

## 히스테리시스

정지 조건:

```python
self.min_distance < self.stop_distance
```

기본값:

```python
self.stop_distance = 0.6
```

재출발 조건:

```python
self.min_distance > self.restart_distance
```

기본값:

```python
self.restart_distance = 0.8
```

정지 거리와 재출발 거리를 다르게 설정하여 경계에서 명령이 빠르게 반복되는 것을 줄입니다.
