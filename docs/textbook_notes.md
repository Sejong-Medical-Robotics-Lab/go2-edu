# 교재 ③ 정합 메모 (교수용)

Gazebo(Classic) 원안으로 구축했으므로 **교재 4장 서술이 원문 그대로
유효합니다** — 4.2의 Gazebo/rviz2 대비·GUI 조작(▶/⏸·Reset·RTF)·sim time,
4.3의 `ros-humble-gazebo-ros-pkgs` 설치 명령, 4.5 도전의 월드 파일 `<pose>`
확인까지 전부 저장소와 일치합니다.

다음 개정 때 참고할 미세 항목만 남습니다.

1. **카메라 영상** — 시뮬레이터에 카메라 토픽이 없어 미션 A-② 표에서
   "없음" 기록이 정답(교재가 이미 허용). 원하면 "시뮬에는 없음, 실기체
   비교 관찰"로 한 줄 명시 가능.
2. **3.3 QoS 복병** — 본 시뮬 토픽은 기본(reliable) QoS라 이 함정이
   재현되지 않음. "실기체 센서 드라이버에서 만난다"로 한정하면 정확.
3. **부록 B ①(넘어진 채 시작)** — 이 스택은 기구학 구동이라 물리적으로
   넘어지지 않음. 증상은 '이상 자세'로 나타나며, 대응은 README §10의
   "Gazebo Reset World → API Reset() → StandUp" 절차. 문구를 "자세가
   이상하면 리셋 후 기립"으로 일반화하면 그대로 맞음.
4. **LiDAR 명칭** — 저장소의 센서 프레임은 `lidar_link`(URDF의 radar 장착
   위치, 자세만 수평). frame_id 조사 미션(3.4·6.2)은 그대로 성립.
